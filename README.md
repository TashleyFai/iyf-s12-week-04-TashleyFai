# Week 4: JavaScript Fundamentals

## Project Overview

This project contains my JavaScript practice for Week 4 of IYF Weekend Academy Season 12.

I worked on JavaScript fundamentals, a calculator, a student grade tracker, and five daily challenges.

## Files and Folders

- `index.html` - Main HTML page.
- `main.js` - JavaScript lessons and calculator.
- `grade-tracker.js` - Student grade management system.
- `daily-challenges/` - Five JavaScript challenges.

## Calculator

The calculator supports:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Remainder (%)
- Exponents (**)

It also handles division by zero and invalid operators.

## Grade Tracker

The grade tracker can:

- Add students.
- Find student records.
- Calculate student averages.
- Calculate subject averages.
- Find the top student.
- Identify struggling students.
- Generate report cards.

## Daily Challenges

1. FizzBuzz
2. Reverse a String
3. Find the Largest Number
4. Remove Duplicates
5. Palindrome Checker

## What I Learned

- How to declare variables using `const` and `let`.
- How to use JavaScript operators.
- How to create functions and arrow functions.
- How to use conditions and loops.
- How to work with arrays and objects.
- How to use `map()`, `filter()`, `reduce()`, and `find()`.
- How to work with JSON.
- How to handle errors using `try...catch`.
